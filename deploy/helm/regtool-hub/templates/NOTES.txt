{{ include "regtool-hub.fullname" . }} is installed in namespace {{ .Release.Namespace }}.

Reach it from your machine:

  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "regtool-hub.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}

Then:

  curl http://localhost:{{ .Values.service.port }}/v1/sources     # the mirror list
  curl http://localhost:{{ .Values.service.port }}/v1/health      # the latest check per mirror
  curl http://localhost:{{ .Values.service.port }}/metrics        # Prometheus exposition

Point the CLI at it:

  export REGTOOL_SOURCES_URL=http://localhost:{{ .Values.service.port }}/v1/sources
  regtool list npm

Check the release:

  helm test {{ .Release.Name }} --namespace {{ .Release.Namespace }}
